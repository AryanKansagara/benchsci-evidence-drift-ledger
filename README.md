# Evidence Drift Ledger
BenchSci develops evidence-grounded preclinical research tools. This independent prototype propagates declared source changes into review packets for dependent experimental decisions.

Run Python 3.11+: `python -m unittest -v`; `python ledger.py --output measured-demo.json`. No packages, keys or network needed. Strict primitive string/bool/integer fields and tuple dependencies exclude mutable payloads from frozen document/claim dataclasses; append-only version storage, SHA-256 content IDs and exact Unicode character spans preserve cited evidence. Explicit structured claim annotations determine entity/condition/predicate/polarity; this program does **not extract or verify scientific claims from prose**. Controlled fixture edits change both source text and its authored annotation; annotations remain trusted inputs rather than inferred truth. Hashes establish identity, not truth or authenticity.

Rules: removed citations become stale; same-context declared polarity reversals become contradicted; changed/missing context or unexplained wording changes require review; whitespace-only and known synonym changes remain unchanged. The highest-priority dependency status propagates to a decision. Unrelated claims and different cell lines are negative controls. Tests compare affected sets against authored gold sets, check span provenance, invalid inputs and immutable history. `measured-demo.json` contains actual rule outputs on authored fixtures, not biological performance evidence.

No BenchSci access, proprietary knowledge graph, clinical data, biological efficacy or experiment-selection validation is claimed. The in-memory ledger is append-only during a process; it is not a signed durable database. Canonical aliases and semantic annotations are authored, not learned. Next work: durable event log, licensed corpus import and independent expert labels.

Existing overlap: BenchSci already supports citations, entity resolution and conflict discovery. This is a source-update dependency experiment, an inferred opportunity, not a proven missing feature. Primary sources (research 2026-10-31): https://www.benchsci.com/platform/knowledge-graph ; https://knowledge.benchsci.com/home/quick-start-guide-selector ; https://github.com/allenai/scifact . No SciFact data is bundled. Python fits rule evaluation and provenance; no inference hot path is present.
